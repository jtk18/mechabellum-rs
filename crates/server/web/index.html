Mechabellum Community Stats

Win rates for Mechabellum, built from replays that players share.

How it works

  1. A small desktop app finds your Mechabellum replay folder and watches it.
  2. It shares your replays with this site, with every other player's name removed first. Only replays are sent.
  3. The site adds them up into shared stats: which units and techs win, patch by patch.

Stats: coming soon

We're still building the stats pages. Once enough replays are in, they'll appear here.

Get the app

Downloads for Windows, macOS and Linux will be on the GitHub releases page. While we test, sharing replays needs an upload key.

Check the code

The app, the replay parser and this server are on GitHub, so you can see exactly what the app reads and what it sends: github.com/jtk18/mechabellum-rs.
